# RedApp 0.7.2 运行变更

本分支基于已发布 v0.7.1 `67be38091b99e211fc5352a3a4cb90fab786856d`。发布状态以远端版本标签和镜像为准。保留 Provider、共享下载/缓存、18 份安装器原文/patch/信任材料和现有指标历史语义，不引入 0.8 的分类、标签、配置继承或新存储后端。

## 数据与模板

SQLite schema 为 7。精确匹配的 schema 5/6 可事务升级；schema 4 先通过既有 schema-5 升级再升至 7，每步独立事务，失败可重试。新增小时下载 sketch、首页置顶/版本、随机排行盐、待物理删除回执和按 UID 持久化的永久删除意图。已有应用 UID、source epoch、配置、缓存、历史和说明保留。更早/未知格式仍拒绝且不导入。升级前停机并备份完整目录，包括 WAL/SHM；回退使用完整备份，不能把新库交给旧程序。

`all` 是公共目录保留厂商 ID。已有同名厂商会明确阻止升级，不自动改名、删除或忽略；需管理员另行处理冲突。容器默认端口 8080、数据目录 `/var/lib/redapp`、UID/GID 65532 和健康检查契约不变，本次未更改 Stacks 配置。

内置实体模板在 `internal/store/entity_templates.json`，与不可变发布协议定义分开。启动只补齐缺失厂商/应用，新增条目默认禁用；公开需要厂商和应用都启用。已有完整键 `vendor_id/app_id` 记录不因来源、Provider、启用状态或模板不同而覆盖。已有自定义说明或显式空白说明保留；兼容内置应用缺少说明记录时可使用模板默认说明。

所有匹配内置模板完整键的应用都不可删除，厂商删除也不能绕过。自定义应用的 slug 只在厂商内唯一，不同厂商可以同名。创建后 ID、厂商归属、Provider 固定。

## 选择性重置与永久删除

模板重置默认不选任何字段。选择后展示当前值与模板值，再提交应用/厂商 revision；说明字段另校验 instructions_revision，冲突整笔回滚。应用可选择名称/描述、图标、启用、中英文说明以及 Provider 兼容的源和缓存设置；Provider 不同时不提供源/缓存重置。源变更沿用新 source epoch，不清空旧文件或历史。重置不删除任何上传图标、缓存、Hosted 文件或历史。

未匹配内置完整键的自定义应用可以永久删除。API 要求 revision、完整 `confirm_key` 和稳定 `confirm_uid`，UI 显示不可撤销确认。事务删除应用拥有的设置、缓存、文件记录、预览、说明、事件、指标历史、源记录、排行及置顶关联；公开 ID 可重新使用，但新应用获得不同内部 UID。迟到的后台观测不能重建被删除 UID 的历史。

删除先校验内置保护、UID 和 revision，再原子关闭目标 UID 的任务准入并持久化待删意图；取消该应用全部 source epoch 的公共读写、release 回源及校验、metadata/cache flight、刷新批次、Hosted 上传/导入，等待任务退出和句柄释放后才删除数据。不取消其他应用，不关闭共享 transport；全局容量上限仍保留。HTTP/2 取消仅针对目标响应流。

等待上限 15 秒；未退出返回 HTTP 409 / `DIRECTORY_DELETE_PENDING`（`retryable=true`），明确“删除尚未完成”，目标应用保持待删并阻止新任务。界面保留确认，可手动重试，不要求重新加载或自动反复提交。重复请求用原 UID 和 revision 继续；公开键被重新创建时，旧 UID 请求不能删除新应用。重启在运行服务前恢复明确的永久删除意图，普通历史软删除不会被自动清除。

物理路径只来自内部生成的对象 ID，持久化清理回执在逻辑删除后处理；失败返回 `cleanup_pending` 并在界面提示，重启继续清理。`os.Root` 与严格路径格式限制清理范围。全局共享上传图标保留为独立资源。厂商有任何应用记录时不能删除。确认框明确会中断正在进行的下载、上传和后台任务。

取消登录返回首页后再次进入后台，布局会立即按已有会话状态重定向到登录页；无须等待状态值变化。返回路径和查询保留，后退/前进、深链、成功登录以及迟到 401 的会话代次保护继续有效。

## 代理与管理交互

出口代理只有一个完整 `server` URL，支持 HTTP、HTTPS、SOCKS5，必须有合法端口，允许百分号编码的 userinfo。后台 GET 原样返回完整 URL 与 dns/revision；不再保留独立 username/password、has_password 或 password_action。空值表示直连。旧独立凭据一次性编码进 URL，CAS 保存后不再重复迁移。公共响应、日志和事件不得包含代理凭据，备份按敏感数据保管。传输切换、URL 边界及 TLS 校验沿用既有行为。

管理页共用 Switch、自动刷新与选择控件；ID 禁用，标题行控件不被拉伸。厂商卡片数量靠标题展示，应用是图标/名称横向项；新增入口单独占第一项，后接至多五个预览，更多项折叠展开并分页。按 ID/中英文名称搜索先过滤再分页。默认显示全部，启用/禁用按厂商与应用的实际组合计算，并区分自身禁用和父级禁用。

仅 query 改变不滚动或转移输入焦点；真实路径切换聚焦主内容。导航搜索保留 IME、选择区和返回导航状态。可见性检查得到相同 CSRF 不撤销当前成功请求；真实登录/退出即使 token 相同也推进会话代际，旧 401 无法注销新会话。取消请求静默；API 错误、非法 JSON、网络失败和意外本地错误分别处理，表单错误不被轮询清掉。

## 公共目录、置顶与排行榜

- `/`：后台排序的置顶应用、近七日排行及全部应用入口，没有首页正文搜索表单。
- `/all?q=...&page=...`：全部有效启用应用，服务端先搜索后分页。
- `/<vendor>`：厂商名称、描述及其应用分页；面包屑为全部 → 厂商 → 应用。
- 导航搜索：异步建议最多四个厂商、六个应用；选择直达详情，未选择按 Enter 前往 `/all?q=...`。编辑、IME 和离开页面会取消旧请求。
- `/admin/api/settings/homepage`：最多 100 个不同完整键的有序置顶列表，revision CAS。禁用项保留配置但不公开展示。

排行按小时持久化每应用 1024 个 HLL 寄存器。使用数据库随机盐的 HMAC 对规范化客户端 IP 做摘要，IP 和逐客户端摘要均不落盘；读取时合并近 168 小时 sketch，不能将每日估计数相加。典型相对标准误差约 3.25%，并非精确人数；窗口以小时计，最早未完整纳入的一小时可能被排除。过期桶不参与查询，后续计数时物理清理。

只有成功公共文件 GET（200/206、传输未取消或失败、长度完整）计入；包括 HTTP cache hit。HEAD、304、失败请求、metadata、图标、installer、管理员预热不计入。沿用现有可信代理 ClientIP 解析，不信任普通客户端伪造的转发头。禁用项不出现在排行榜。

公共列表和建议接口有分页/数量上限；兼容 bootstrap 仍携带启用应用描述，当前未改为完全按需加载。新路由支持直接访问和刷新。

## 使用说明文档

中英文说明支持 Markdown、原始 HTML、JavaScript 和外部资源。Goldmark GFM 保留原始 HTML；实际独立 HTML 响应经文档解析执行脚本，不依赖 innerHTML。说明 iframe 不加 sandbox，文档 CSP 单独允许这些资源；后台 SPA 保持原有 `script-src 'self'`。

说明是管理员控制的受信任同源内容，**不是安全隔离边界**。服务端仅注入公开资料，不传入密码、会话或代理设置；但同源脚本本身仍具有浏览器同源能力。后续边界收敛已有 [issue #4](https://github.com/PMExtra/RedApp/issues/4)，本轮不重复创建。

受控占位符为 `{{base_url}}`（有效公开地址，无尾斜杠）、`{{app_path}}`（`/vendor/app`，有前导无尾斜杠）、`{{app_name}}`、`{{app_key}}`、`{{public_origin}}`、`{{app_url}}`、`{{install_commands}}`。未知占位符保持原文，不执行任意服务端表达式。Codex/Claude 双语默认说明作为模板配置保存，安装命令由公开地址和既有 descriptor 生成。保存空说明不会偷偷恢复默认。

## 验证与边界

回归入口：

```sh
make test                         # Go race 与安装器 Shell/治理
make check                        # gofmt 与 go vet
cd frontend && npm run typecheck && TZ=America/Los_Angeles npm test
cd .. && make build
python3 scripts/test-http-cli.py
python3 scripts/test-data-cli.py
node scripts/test-instructions-document.mjs
sh scripts/test-docker-local.sh
```

新增回归还覆盖目标 UID 跨 epoch 取消、release 校验取消、metadata/cache flight 与刷新批次、Hosted 导入、HTTP/2 响应隔离、待删超时/提交失败/重启与重复请求，以及取消登录后重复进入、历史导航和深链。新增行为回归覆盖模板不覆盖/默认禁用、全键删除保护、选择性双 revision 回滚、schema-5 既有业务表快照、Hosted 真实文件及升级前后下载保留与 `all` 冲突保护、代理单向迁移、合并去重/过期、删除范围和迟到写入保护、实际下载计数及缓存命中、焦点/IME/返回导航与会话重检。说明文档脚本测试使用真实 Go HTTP 服务和本地无害脚本，在 Happy DOM 中执行；它不替代原生浏览器 CSP 或视觉验收。

交付包保存真实日志、安装器摘要对比、独立恢复记录及发布门禁结果。发布流程要求精确 main 提交通过完整 CI 后才创建版本标签，再按不可变 digest 验证双架构镜像。无 GUI/截图、真实官方客户端或用户环境部署；不修改用户真实数据、Stacks、仓库保护规则或权限。

0.7.4 中英文默认说明直接用 `{{base_url}}{{app_path}}` 拼接 Markdown 安装命令；仅完全匹配 0.7.3 默认值的语言内容自动更新，自定义与显式空值保留。`{{install_commands}}` 保留旧输出兼容自定义说明。复制增强仅作用于 Markdown 代码节点，原始 HTML 不自动增强；代码块按钮位于右上角，行内按钮可悬停或键盘聚焦使用，复制内容保留代码空白和换行。


## 0.7.5 公开说明与导航修正

公开详情、卡片和厂商目录优先使用当前语言的厂商名称，再回退英文、兼容 publisher 和厂商 ID。后台登录页不显示右上角“应用”链接；登录后侧栏使用独立的“应用管理 / Applications”标签，其他标题与面包屑不变。

Markdown 块代码采用 0.6.4 的浅色标题栏、复制图标/文字按钮、深色代码区与圆角边框。Shell/PowerShell 标题由围栏语言映射，其他语言保留其语言名，无语言时显示“代码 / Code”。复制仅取代码文本，保留空白换行；块代码和行内代码共用复制中禁用、可见成功/失败反馈及键盘焦点行为，按钮提供 hover/active 状态。不可用的剪贴板显示手动复制提示。原始 HTML 不自动增强，旧 install_commands 输出保持兼容。

内置默认说明移除重复的独立 Shell/PowerShell 标题；只对与旧默认完全相同的语言内容迁移，保留自定义正文标题与显式空值。顶栏账号/语言菜单共用 210px 首选宽度、末端对齐、弹出间距及视口防越界，表单下拉继续按字段/内容决定宽度。CLI DOM 与几何测试不代表 GUI 视觉验收。


## 0.7.6 复制反馈与应用卡片修正

Markdown 代码复制成功后，按钮显示 check 图标与“已复制 / Copied”，保持禁用 3 秒再恢复复制图标、文字和操作；复制失败立即恢复操作并保留可见错误提示。块代码与行内代码共用此逻辑，原始 HTML 不增强。

Codex 与 Claude 的中英文默认说明分别在命令前提示 Linux/macOS 使用 Shell、Windows 使用 PowerShell。仅精确匹配历史默认内容的语言字段迁移，自定义内容与显式空值保留。详情页移除安装器应用的系统“Installation instructions / 安装说明”眉题，不删除说明正文中的自定义标题。

应用卡片统一为左侧图标、右侧应用标题及其下方厂商；首页、目录和备用列表复用相同组件。排序柄统一使用上下双向箭头、中间横杠的专用图标，无点击排序动作，保留拖拽及现有键盘无障碍操作。CLI/DOM 回归不构成 GUI 视觉验收；HTTP Range、gzip/br 与 0.8.0 不属于本次修改。

0.7.6 的指标名称统一为“回源流量 / Upstream traffic”“回源速率 / Upstream rate”“分发流量 / Downstream traffic”“分发速率 / Downstream rate”，界面不附加压缩或载荷说明；指标键、计数计算与历史数据不变。HTTP gzip/br 支持已在[项目规划](roadmap.md#backlog--not-planned)记录为 Not planned，保留 identity 回源。

## 0.7.7 卡片、版本信息、安装选项与品牌资源

公开卡片及详情复用已知版本组件。API 从当前 application source epoch 的 `app_versions` 记录，按对应 Provider 的版本比较规则选择最高已知版本（包括有效预发行版本），使用该条记录的 `first_seen_s`。这不是源站发布时间、最近轮询时间或 `latest` 通道的别名；查询展示不触发同步。无已知版本或无有效发现时间时明确显示未知；非版本 Provider 不展示。时间按用户语言显示相对时间，每 30 秒更新，悬停或键盘聚焦可查看浏览器本地完整日期时间。

Codex Shell 使用 `--release`，PowerShell 使用 `-Release`；只支持 `latest` 和指定版本，当前不支持 `stable`。Claude Code Shell 使用位置参数，PowerShell 使用 `-Target`，支持指定版本、`stable`、`latest`。默认说明为每个选择提供独立可复制示例，`1.2.3` 是需替换的示例版本，不保证该版本存在；没有改变安装器或通道语义。仅精确匹配历史默认说明的语言字段迁移，保留自定义与显式空白。

用户指定的 Anthropic 厂商 SVG 与 Claude Code 应用 SVG 作为固定白名单编译内置，来源与许可见[素材记录](../internal/apps/builtin/assets/README.md)。新实体/显式重置图标使用新模板；已有管理员图标（包括留空）不自动覆盖。应用图标保留禁用应用的公开访问隔离，后台认证预览可用；厂商标志作为固定公开品牌素材提供。没有增加运行时 CDN 请求。

公共卡片使用紧凑的图标/标题/厂商头部、独立说明和版本信息底栏；标题固定 20px，长文本可换行。后台 Versions 左栏每个版本为完整单一选择按钮，统一展示版本、相对发现时间、请求次数和选中状态，保留全部版本、键盘操作及分页；右侧 Resources 表格不改版。

厂商与应用设置复用标题区启用开关，仅修改草稿，保存时提交；加载、忙碌或只读时不可用。模板重置选项与按钮使用共享间距，窄屏换行保留横纵间距，重置语义不变。

在授权的云环境 Chromium 中验证中英文、1440px/390px：真实 SVG 加载、版本行选择与键盘完整时间提示、全部版本、标题开关不即时提交、模板按钮间距、原生折叠反复切换和页面无横向溢出。未宣称主会话已完成原始附件对照；发布依据为本轮云浏览器与 CLI/CI 行为验证。

章节型折叠标题复用 `section-heading`：诊断指标、历史数据表、路径测试和来源列表的 summary 内容垂直居中。标题下边距仅在 details 展开时生效，折叠时为 0；反复切换不保留空白。表格内错误/技术详情、清理预览等紧凑 summary 不增加章节间距，继续使用原生 details/summary 语义与键盘行为。
