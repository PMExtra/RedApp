# 0002：Provider 在编译期定义，不支持插件

## 背景

每种分发方式（info、hosted、http-cache、codex、claude-code）都有自己的上游协议、信任链和授权规则。插件或运行时加载的代码会把这些安全边界交给配置文件或外部代码决定。

## 决定

- Provider 的种类和实现编译进二进制，由代码中的注册表选择。
- 预置与导入的 YAML 只能引用已有 Provider 并填写其参数，不能携带可执行声明、命令字符串或可加载代码。
- 新增 Provider 需要修改代码并经过代码审查。

## 后果

- 信任边界可以通过代码审查和测试完整覆盖。
- 新增一种分发协议需要发布新版本。
- 安装器验证器遵循同样原则：`scripts/test-installers.py` 只能选择已审核的协议实现。
