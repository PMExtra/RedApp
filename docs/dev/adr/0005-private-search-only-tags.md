# 0005：Tag 私有，仅用于搜索

## 背景

0.8.1 把 Tag 改为每个 App 自己的自由文本（不再有全局字典），并删除了基于 Tag 的关联推荐。自由文本可能包含内部用语，不适合公开展示。

## 决定

- Tag 由管理员维护，作为 App 配置的一个完整字段参与模板覆盖、重置、复制和导入导出。
- 后台搜索、置顶候选以及公开的 `/api/catalog`、`/api/search` 会匹配 Tag：去掉前导 `#`、折叠大小写后做字面子串匹配。
- 公开 DTO 和公开页面不包含 Tag，也没有按 Tag 筛选的入口。

## 后果

- 管理员可以用 Tag 提高搜索命中率，而不暴露 Tag 内容。
- 通过搜索结果仍可间接推断某个 App 含有某个 Tag，因此 Tag 里不能放敏感信息。
- 若要实现基于 Tag 的推荐，需要新的 ADR 重新评估公开范围。
