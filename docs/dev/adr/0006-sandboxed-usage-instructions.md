# 0006：使用说明文档在无同源权限的沙箱 iframe 中运行

## 背景

每个 App 的使用说明由管理员编写，支持 Markdown 和原始 HTML/JS，交互内容需要执行脚本。此前文档在同源、未加 `sandbox` 的 iframe 中运行，脚本可以访问 RedApp 的存储并以访问者身份调用同源 API。一旦说明内容被篡改或引入了第三方脚本，影响范围就扩大到整个站点。

## 决定

- 使用说明仍视为受信任的管理员内容，允许 HTML 和脚本。
- 文档在带 `sandbox` 属性的 iframe 中渲染，**不授予** `allow-same-origin`。脚本运行在不透明 origin 中，不能读取 RedApp 的 Cookie 或存储，也不能以同源身份调用 API。
- 文档响应使用独立的 CSP，与 SPA 的 CSP 分开。

## 后果

- 说明中的脚本不能调用 RedApp API；需要的数据由服务端渲染进文档。
- 父页面不能再直接读取 iframe 内容（例如用于自适应高度），需要改用 `postMessage` 等跨 origin 方式。
- 依赖同源访问的既有说明内容需要调整。
- 该决定与阶段 0 的安全修复同步实施；落地之前，代码仍是同源、未沙箱的 iframe。
