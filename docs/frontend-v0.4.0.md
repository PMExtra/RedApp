# v0.4.0 前端设计

目标：公共安装入口与管理后台共享完整产品框架、双语和交互规范，保留现有缓存、版本、事件、代理、清理及指标历史能力。

## 信息结构

- 共同顶栏：RedApp / Application Redistribution、语言切换；公共页面右上角管理员入口，后台右上角账号菜单。账号菜单容纳修改密码与注销。
- 公共页：应用目录 → Codex CLI 详情。详情以两种一行安装命令和复制操作为核心，随后给出操作步骤、审查脚本入口和必要限制。保持匿名访问与安全 origin 推导。
- 管理后台：桌面侧栏、窄屏横向导航，分为概览、版本与资源、事件、设置。页面标题、说明、快照和刷新操作有固定位置。
- 概览：优先展示磁盘、回源/分发速率与成功下载；完整 43 项指标按主题分组，仍可打开历史。历史窗口、覆盖和缺失语义保留。
- 设置：元数据时效、代理、版本清理分别成卡片；修改密码移出设置，使用账号菜单打开模态框。
- 共同页脚：RedApp 版本及服务端 OS/架构，由只读公共接口提供，不把浏览器平台冒充服务端架构。

## 视觉与交互

统一浅色背景、深色文字、青绿色主操作，限制强调色数量。采用一致的容器宽度、间距、圆角、边框、表单标签、空态和错误态。宽表只在表格容器内横向滚动，窄屏不隐藏关键操作。图标用于导航和状态，并始终提供文字或可访问名称，不作为唯一状态提示。

自动刷新是带图标、文字与 aria-pressed 的按钮；手动刷新独立，避免并发轮询。错误保留上次成功快照并明确提示，提供重试。修改密码校验确认字段，防止重复提交；提交中不允许误关闭，成功后清空凭据并退出登录。菜单支持方向键、Escape、外部点击与焦点返回；模态框使用原生 dialog。

## 语言和时间

完整支持 English / 简体中文，首次按浏览器偏好选择，用户选择保存在本地并应用于公共页和后台。文案、可访问名称、指标名称、状态、错误提示和时间单位集中维护。产品名、代码命令、版本号及原始诊断数据不翻译。后端日志及原始诊断允许英文；前端操作失败的说明提供双语。

快照、版本发现时间、资源和事件时间按浏览器本地时区显示；历史聚合仍为 UTC，图表和数据表明确标注，避免改变已定义的统计语义。

## 安全和验收

API 会话、CSRF、代理凭据保留/替换/清除、origin 与路径校验保持。公开信息仅含应用简介、安全 origin、版本和平台，不能取得管理数据；页面不触发回源。所有字符串作为文本渲染，CSP 不放宽，不引入 CDN 或外部运行服务。

通过 CLI 执行类型检查、Vue DOM 单元交互测试、Go race、HTTP/CLI 与构建一致性验证。包括语言切换、菜单键盘、模态框取消/失败/重复提交、刷新重入与会话过期、清理过期预览、窄屏所需 DOM/样式规则。CLI 通过不代表视觉验收。已使用本地 fixture 在 Chromium 151.0.7922.173 中完成中英文、1366×900 与 390×844 四种组合的 20 组交互检查，并审阅公共目录、详情、后台概览及代表菜单/模态框/设置截图。修正账号按钮 ArrowDown 向菜单容器冒泡导致焦点多移动一项的问题。验证不访问生产服务，不安装 Codex；其它浏览器与 Windows/macOS 实机安装仍需另验。

品牌素材使用用户提供的 OpenAI 标志，原文及出处记录于 Codex 模块；不是 Codex 专属图标，来源页标记 PD-textlogo 并注明商标限制，未与远程原件逐字节比对。不得用自绘标志冒充官方素材。
