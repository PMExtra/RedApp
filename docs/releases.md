# 版本说明

## v0.6.1

修复前端会话竞态：旧请求的 401 在新登录完成后到达，不再注销新会话或清空新 CSRF；JSON 解析期间取消的请求也会丢弃结果。当前会话的 401 仍清除敏感状态并停止轮询。

测试按实际契约整理：删除使用旧数据库/路由的浏览器脚本；协议负例从独立有效材料只改变目标字段，并补齐有效清单中的顶层/嵌套重复键；Claude Shell 平台、目标与启动入口生命周期分开覆盖，新增真实 wget-only 下载以及 jq/内置解析各自的失败保护。两个 100-reader 场景、签名、隔离、续传、清理、崩溃恢复和 Windows PowerShell 7/5.1 覆盖均保留。详见[测试审计记录](test-contracts-v0.6.1.md)。

本版本继续使用 v0.6 数据格式；没有数据库迁移或安装器字节变更。发布仍要求精确 main 提交的双架构 Linux 完整 CI、Windows 回归及镜像 digest 运行门禁；未执行 GUI 或真实上游二进制验收，不修改用户部署。

## v0.6.0

**破坏性多应用架构升级：必须使用全新空数据目录。** 不导入旧版配置、缓存或历史；检测到旧版或未知目录会拒绝启动，旧目录保持不变。部署改为显式 JSON 配置，旧逐字段 CLI、部分环境变量和旧公共/隐式 Codex API 路径不再兼容。先保留旧实例的完整备份，再按[升级说明](multi-application-v0.6.0.md)创建新实例；不能将新数据库交给旧程序读取。

统一 vendor/app registry、共享 catalog/downloader 与 schema 3 的应用隔离。公共详情及分发根为 `/openai/codex` 和 `/anthropic/claude-code`，后台使用显式应用 API 与独立 SPA 页面。PUBLIC_URL 支持持久化后台覆盖、环境默认、安全请求 origin 的优先级；清除覆盖可恢复环境默认，设置更新由 revision/CAS 防止覆盖他人修改。

全局概览显示 16 项常用和 25 项默认折叠诊断指标；历史读数显示本地时间、原始精度、单位及缺测/覆盖语义，支持键盘和触摸事件。停止两项冗余指标的新写入/采样/展示但保留历史自然过期和错误详情。修复 TTL 切应用失败时的旧值、全局版本漏计 Claude，以及轮询误清设置错误。安装器原文、严格 patch 和信任材料保留原始字节，每日检测从统一 descriptor 获取新路径。

发布必须先通过精确 main 提交的 Linux amd64/arm64 与 Windows PowerShell 7/5.1 CI，再创建 `v0.6.0` 标签。镜像发布后按不可变 digest 验证双架构及健康、持久化、锁和崩溃恢复。无害测试程序只验证安装器与启动入口，不代表真实 Claude 二进制运行、升级控制或企业生产网络已经验收；本轮无 GUI/截图，也不修改用户部署。

## v0.5.0

新增 Claude Code 原生制品分发，与 Codex 共用一个进程、SQLite、磁盘缓存、代理和管理界面；签名清单验真后才授权资源，渠道、历史与清理按应用隔离。中英文公共页提供两种应用的安装命令。Claude 受管启动入口为子进程设置 `DISABLE_UPDATES=1`，保留官方二进制字节；真实 CLI 运行期仍需企业自行验收。

升级前停止服务并备份完整数据目录。SQLite 自动迁移到 schema 2，保留已有 Codex 历史和缓存身份；旧版本不能读取新 schema，降级须恢复升级前备份。两应用安装流程及限制见 [Claude 说明](claude-code-v0.5.0.md)和[运维](operations.md)。

新增每日官方安装器检测；仅在原文变化且严格 patch、隔离测试和产物校验通过时创建草稿 PR，不自动合并。首次真实检测无变化，真实变化分支的容器与 PR 写权限尚待验证。安装器保持最小必要修改，第三方许可独立保留；没有取得额外再分发授权的声明，也不捆绑 Claude 二进制。精确验证范围见[验收记录](acceptance.md#v050-claude-code-与每日安装器维护)。

## v0.4.1

新增持久化双语站点标题、副标题和通用页脚声明，保留默认值兼容旧数据目录；所有自定义文案仅按纯文本展示。公共导航与内容使用相同宽度，公共页脚隐藏架构，后台用版本后的括号简写，RedApp 源码链接固定不随标题改变。语言、版本、代理和历史计数视图统一使用支持键盘的下拉组件。复制按钮按浏览器能力显示；公共安装页聚焦终端用户，管理员说明集中到文档。

回源指标明确为已读取的 HTTP 载荷，分发指标明确为外部压缩前字节；修复写盘或长度检查失败前已读取字节漏计。仍禁用回源 HTTP 压缩，历史指标键、累计值和保留策略不变；旧版漏计不能回补。配置、计数边界和本轮未验证项见 [v0.4.1 说明](frontend-v0.4.1.md) 与[验收](acceptance.md)。本轮中英桌面/窄屏浏览器验收通过；镜像发布仍以该标签对应的 Actions 完整构建、双架构 manifest 与按 digest 运行门禁为准。

## v0.4.0

公共应用目录和 Codex 安装详情，与管理后台共用重设计后的导航、组件、English/简体中文切换和版本/架构页脚。新增账号菜单与密码模态框；刷新开关使用图标按钮，快照按浏览器本地时间显示。历史统计、维护能力、安装参数和安全 origin 规则保留。用户提供的 OpenAI 品牌标志已内置，来源页 PD-textlogo/商标标签已核验（未比对远程字节），中英文桌面/手机浏览器交互和代表截图审阅已通过，详见[本轮验收](acceptance.md)。双架构镜像需通过该提交的原生 CI 与发布后 digest 拉取运行门禁，结果以对应 Actions 记录为准。

## v0.3.0

- Vue 管理页面使用英语，提供移动端布局、安装命令复制和自动换算的磁盘单位。
- 新增全局指标历史：43 项固定指标，最近 24 小时分钟数据、7/30 天小时汇总，以及交互图表；重启、计数器重置和采样缺口不会伪造增量。
- 支持统一配置 HTTP/SOCKS5 回源代理；管理 API 不返回已保存的代理凭据。
- `REDAPP_PUBLIC_URL` 可选，支持安全地按请求推导 origin；仅信任已配置的代理，并拒绝非法 origin。
- 构建使用 Go 1.27.1、Node.js 24.19.0 和 Debian trixie；运行镜像仍不需要 Node 或外部运行服务。

升级时保留 `/var/lib/redapp` 数据卷，先备份 SQLite 与数据目录。历史表按需创建，不改写已有累计统计；历史采样从升级后的运行开始。旧版 v0.1.0 使用 `/data`，需按运维文档迁移。`latest` 跟随发布，需要固定版本时使用 `v0.3.0`。

安装器默认仍选择 `CODEX_RELEASE` 或 `latest`，CLI 二进制保持上游原样。安装器仅使用本服务下载；Codex 运行期/API 及其更新检查仍需企业出口策略。Windows/macOS 实机安装、生产上游链路和 GHCR 匿名访问仍为独立验证项。

验证记录见[验收](acceptance.md)，部署和备份见[运维](operations.md)。
