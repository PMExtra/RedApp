# 项目规划

## v0.8.0 — 配置 overlay（方向已定，暂停实施）

采用模板默认值叠加逐字段显式 override；当前仅记录规划，不纳入 v0.7.10 实现，不改变现有数据模型。

- 未覆盖字段继承模板；显式空值也是有效覆盖。界面分别展示继承/自定义状态与值差异，即使自定义值等于模板值也保留覆盖状态；重置表示取消 override，恢复继承。
- 双语字段按语言独立覆盖；有序列表作为整体覆盖，不逐项合并。
- `enabled` 是独立运行状态，不继承模板、不参与模板重置；实体身份和 Provider 不随模板更新改变。没有模板的自定义实体保持独立配置。
- 保存只提交用户明确的设置/取消覆盖操作，不将展开后的有效配置整份写回。模板更新时，同步有效配置及受影响源版本的事务处理，避免配置与源版本不一致。
- 不考虑旧数据迁移或历史兼容。0.8.0 仍暂停实施，具体实现待后续授权。

## Backlog — Not planned

### HTTP gzip/br 压缩支持

状态：**Not planned**。项目传输的大多是已压缩的安装包，再增加 HTTP 压缩的收益有限，却会增加缓存表示、验证器、Range 续传与流量计数的复杂性。保留现有 identity 回源行为，不实现 gzip/br 支持。界面采用简洁的回源流量、回源速率、分发流量、分发速率名称；技术统计定义继续见[指标口径](metrics-history.md#制品流量与压缩口径)。
